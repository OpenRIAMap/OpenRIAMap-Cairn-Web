# 可选字段空值统一清理

## 生效范围

正式前端在完整测绘采集、标准工作流新建与提交、JSON／中继包／地图要素导入，以及标准与外部工作流的再编辑保存时，依据当前配置的有效字段声明清理工作副本。

- 非必填、未声明 `emptyValue: preserve` 的普通字段：省略 undefined、null、空字符串及纯空白字符串，包括普通空格、全角空格、制表符和换行。
- 不修剪非空文本，不删除 0、false、非空错误值或数组中的位置；非空错误类型继续交给原核验器阻断。
- 根据字段值结构和标准工作流重复组声明，清理对象行内已声明的可选子字段；保留必填子字段、完整行及未知属性。
- 保留静态和条件必填检查；清理前已生效的必填条件不能因为条件来源字段被清理而消失。
- 配置明确允许保留的空值、自定义未知字段及创建信息保持原有语义。

例如，将道路 Speed 从 4.5 清空后保存，输出不再含 Speed 键；导入 `Speed: "　\t "` 或 `Speed: null` 也省略该键。数值空白不会再转换为 0；数字保存值下拉框也采用相同的空白保护。

没有修改地图加载数据的原始快照。旧记录在导入／编辑后的工作副本中清理，随后仍按正常中继包提交、审核、发布流程更新云端。

## 实现边界

- 统一清理：`src/configStudio/optionalFieldValues.ts`。
- 在数值转换前处理工作流输出；提交前再次处理完整记录。
- 导入和再编辑不执行新建默认值回填，保留原创建信息和无关未知属性。
- 实际完整测绘和多要素合并保存，以及登记的外部工作流桥接入口接入同一规则；错误以现有提示流程返回。
- 无需迁移配置 JSON 或修改配置契约版本，也没有修改 CAM／环境变量或部署 SCF。
- 仓库内共享核验产物及来源摘要已重新生成，以通过现有可重复构建检查；没有改变服务端审核发布的业务流程。
