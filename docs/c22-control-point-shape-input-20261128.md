# 控制点直接编辑、连续插入与图形输入

实施依据：2026-11-28 综合蓝图 v1.2。基线为 Web main `77a871b5293d40919192095dfacbdb0454bb3682`；核对正式配置 r167 / c22。本轮交付 Web PR，配置、Pipeline、SCF、CAM 及正式数据均不写入。

## 操作变更

- 控制点“修改”支持直接拖点和点击当前线段插入点。“删除点”是同一修改会话内的开关，切换会清除选择，保留工作几何和撤销／重做；独立添加、删除入口移除。工具保存应用到当前绘图草稿，图层仍使用原保存流程。未修改的工具保存不增加空历史。
- “插入”通过独立浮窗一次选择当前环／线的控制点。后续地图、手动、批量、曲线和图形输入按 `A→P1→P2→原下一点` 保序写入。关窗不停止插入；重新选择未完成时保留旧目标；工具行“插入启用”和面板“清除选择”停止模式，恢复末端追加。
- 插入状态只锁定其他控制点工具及部件／内洞结构，不使用修改事务的整组冻结。显示控制点与输入独占分别管理，手动／曲线／图形仍可使用。数组、完整数组和反转继续复用原流程。
- “手动输入／曲线输入”同一行增加“图形输入”。圆、椭圆、正方形、矩形和正多边形先产生临时预览，可放置、整体移动、旋转和拉手柄；多边形还可拖顶点。切换图形回到本次放置中心并重置变形与旋转。
- 图形边数与输出点数独立；直边图形保留角点，再按边长分配额外点；曲边按弧长采样。输出量化到 0.1，量化退化、无效拓扑或上下文变化会阻止写入并保留预览。只有点击“输入”才一次写入有序轮廓，并形成一步主绘图历史；面闭合沿用宿主规则，线的完整轮廓末尾补首点并明确显示实际坐标数。

## 写入与事件边界

`PointSequence` 的身份和游标仅存在于前端内存，不写入坐标或要素字段。所有新增入口接入同一写点方法；完整数组／草稿恢复仍为整体替换。主绘图历史保存坐标与对应的内存身份，撤销中间插入不会删除原尾点；停止模式不会由重做自动重新启用。起点失效则停止并提示。

修改、选择器、坐标工具提交及手柄均绑定当前草稿上下文，旧事件不能写入另一个世界、要素或部件。手动输入允许同一目标下继续正常绘制，但旧窗口不会把未提交坐标改投新的目标。坐标窗口互斥时保留各自显式关闭边界；活动图形／曲线预览不会穿透到主绘图加点、撤销或保存。

直接编辑使用稳定的 Leaflet 点实例；拖动预览按帧更新，结束时校验、一次入栈，保持原高度。线段命中使用约 8 CSS px，点优先；空白不搬点。关闭／失焦／只读或上下文变化会结束相应指针占用并恢复地图平移。图形预览与测量图层分离，不新增测量模块的占位功能或绘图插件。

## 验证入口

- `npm run test:control-point-input`：保序输入、身份恢复、闭合边、混合历史、无变化历史及五种图形的采样和非法值。
- `npm run verify:ci`、`npm run build`，并执行既有完整数组、多部件和 c16 回归。
- `control_point_input_acceptance.py`：本地真实组件、真实鼠标按下／移动／松开；覆盖直接拖动、线上插点、删除状态、连续历史、关窗保留插入、取消重选、手动单点／批量及曲线插入、五种图形、尺寸／旋转／顶点手柄和 800 点拖动。已接入既有浏览器 CI。
- 隔离 Edge 正常生产构建页面：通过 JSON 对话框导入两个临时主／附属面，正常再编辑拖点、选择插入位置和批量填坐标；停止插入后仍能撤销／重做中间新增点。图形预览期间保存被锁定，关闭不改主草稿。正常保存并通过 UI 下载标准 ZIP，复核坐标、创建信息、修改人及主附属引用。
