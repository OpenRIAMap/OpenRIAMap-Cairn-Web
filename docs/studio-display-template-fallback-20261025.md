# 仅复制显示模板时的字段取色回退

分类重构的 MTL 山线需要借用 ROD 线显示，同时保留自然要素字段，不能引入 Speed、ConnectL、Blacklist 等道路业务字段。原初始化器在关闭字段同步时直接拒绝模板内的 color 依赖；完整同步又可能与目标父级的固定字段定义冲突。

使用“使用其他分类模板”，关闭“同步字段设计”和“同步信息卡设置”，保留几何、显示同步。如果显示中的本地字段取色引用了目标不存在的字段，且该项有明确回退色，则复制为该回退色的固定取色，并逐项记录到分类创建报告。目标已有的字段取色保持原样。未提供回退色、标签主来源、条件、外部目标等依赖仍严格核验。

不新增持久化字段、不调整 c15 契约或 SCF 内核。源分类不改变；完整字段同步的既有行为保持。

验证包含实际 ROD → 自然线父级的单元回归、缺失标签/无回退色负例，以及真实浏览器模板选择、关闭同步、创建、核验、放弃草稿的操作回归。

同轮补齐工作流用途区的四级“编辑作用范围”。修改输出分类后，作者可以显式修复原 editor.scope；旧范围继续严格阻断，无静默改写。没有声明范围的新工作流，启用编辑前按实际候选的共同祖先初始化范围，再进行既有回填及输出核验。继续使用现有 editor.scope 字段，不改变契约或编辑优先级。
