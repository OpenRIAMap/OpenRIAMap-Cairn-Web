# c22 审核与编辑面板交互修复

实施依据：2026-11-27《c22 审核检查进度、长内容滚动与编辑操作优化蓝图 v1.1》。基线为 Web main `19e4ea10800c27af1ecec9453ff4391c1144f209`，正式配置 r167 / c22。

## 行为变更

1. 发布前检查使用启动时的包、决策修订、状态板和操作者快照。改变列表勾选不结束轮询或隐藏报告；恢复相同范围可复用仍有效的结果。报告是否显示与是否允许发布分别处理，范围、版本、身份、Gate、协议和未保存状态继续限制发布。网络失败或关闭后重新进入，通过原按钮续查同一幂等任务。
2. 审核报告、待审核包列表、图层列表、整体／当前 JSON 和测量结果使用独立限高滚动区域。鼠标在区域内滚动不穿透地图；操作区不随大文本增长。普通工作流表单仍自然延长，发布记录和审计保留专用的顶部及滚动布局。
3. 再编辑顶部只保留撤销／重做。原生与 TRP 外部编辑在编辑人下方统一显示红色放弃、绿色保存，沿用原保存与取消处理、身份及结构校验和事务锁。新建和合并复用表单不增加编辑保存按钮。
4. 控制点相关六个桌面窗口移出边栏注册，使用现有浮动拖窗；独立完整数组也保持浮动。窗口按可用地图和视口约束位置、长数组内部滚动，切换皮肤不会丢失未应用的文本。移动端仍用原 compact 容器。
5. 包列表通过实际详情包 ID 标记“当前详情”，使用强调边框、背景与文字标识，覆盖浅深色。标识随成功切换／关闭更新，独立于发布勾选；关闭取消或切换受阻时继续指向原包。
