# 普通分类建树与安全删除（P0）

本轮只补齐工作台操作能力，继续使用 c15；没有迁移正式分类、数据或发布配置。

## 普通建树

在“新增分类”的几何下拉框中可选择“暂不指定”。创建后使用“暂存节点”，即可继续选择、新增或编辑子分类。暂存只保留普通分类草稿，不写入本地活动配置，不进入 Class 树隔离模式。页面关闭后仍经既有缓存确认流程恢复。

“暂存节点”只允许未完成末端暂缺几何；结构、绑定及其他错误仍会阻断。建树完成后使用“核验分类草稿／保存分类草稿”，或者当前节点的正常“核验／保存”。最终分类必须直接指定或继承明确几何。

核验保存到本地配置后，可使用既有 Class 树导出分享；文件导入时才进入 Class 树隔离编辑。现有导入核验、总控保存和放弃机制保持。

初始化时优先复用“使用其他分类模板”。信息卡的合法历史回退来源（例如 height 的 Height 别名）原样保留；主要字段、显示来源和未同步依赖仍严格检查。

## 删除

“删除当前分类及其子分类”预览当前节点和全部后代，列出节点数量、当前挂载数据占用及核验问题。确认仅建立整包候选，不删除要素数据，不自动删除工作流、表格、按钮或导航设置。

可切换设计区域逐项修复引用，再使用顶部整包核验保存；正式记录仍占用被删除分类时，工作台的整包核验、全局核验及最终保存均阻断。这里只能核对已挂载的数据，正式迁移收尾前仍须按迁移蓝图重读并挂载全部待核查世界。

工作流工具栏的“删除工作流”同样暂存到整包候选。放弃整包草稿可恢复分类和工作流；删除最后一个子分类时重新检查父级末端几何。
