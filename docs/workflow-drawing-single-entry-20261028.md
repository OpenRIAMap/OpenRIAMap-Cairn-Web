# 测绘部件与内洞统一入口修复

2026-10-28。基线：`27de2ed86922cf071fe0a7bd5912ff753be63fe1`，正式配置 r93 / c17。

工作流绘制页原来的“添加部件”“添加孔环”通过另一套追加器操作几何，绕过主测绘编辑器，并且只搬运当前路径。现在删除这两个入口及其追加协议，结构操作统一由原“多部件和内洞设置”管理。工作台试运行复用同一个 Runner，同时修复。

## 实际入口差异

| 位置 | 变化 |
| --- | --- |
| 通用工作流绘制页及工作台试运行 | 删除“添加部件”“添加孔环”；没有替代入口 |
| Runner 历史内嵌辅助点分支 | 删除已失效的“进入…绘制／采用…”分支；原有独立辅助绘制任务保留 |
| 原“多部件和内洞设置” | 保留原位置、界面和控件；接收当前任务实际分类的权限 |
| 原撤销/重做、键盘、控制点和数组编辑 | 编号显示期间服从同一只读状态；关闭编号后继续编辑 |
| 原暂停/恢复、预览样例、铁路/车站/TRP、两种合并工具 | 保留用途，不新增几何结构入口 |

`NativeDrawingSession` 只归档和恢复完整草稿；Runner 不维护部件/洞追加器。完整草稿包含全部几何、活动部件/洞、面板、编号锁定、当前路径/重做栈和原始高度元数据。暂存和恢复不截断未完成或与新分类不兼容的草稿。

重复捕获采用完整替换语义。离开任务前归档，进入正确模式后恢复；同一活动任务重入不重新初始化。换世界暂停必须通过已有恢复入口继续，界面布局变化不再清空草稿。未完成结构清除旧有效预览并阻断保存。条件关闭的输出不进入最终保存批次。

分类权限复用现有 `drawingAllowsParts`，接入实际几何消费者。禁止多部件不禁止面内洞。已有多部件草稿改选禁止多部件分类时，保留草稿并阻断不兼容保存；不自动删除部件。编号只读保护同时作用于入口和最终写回，正常工具事务仍可提交。任务切换时沿用原工具的完成/放弃确认，用户拒绝后保留待编辑内容。

原始点的“没有输入 Y”与规范几何的显示缺省高度分开保留，防止覆盖工作流高度字段中的合法 `0`。这属于内存草稿信息，不新增配置或要素属性。
