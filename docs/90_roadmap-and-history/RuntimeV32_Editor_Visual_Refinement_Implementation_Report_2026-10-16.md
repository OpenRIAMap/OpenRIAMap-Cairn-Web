## 2. 关键问题的前后结果

- **验证器重叠**：修改前 600×1000 下与编辑区重叠约 38 px；修改后上下分区保持 12 px 间隔。实际窗口较矮时允许外层垂直滚动，编辑区保留自己的滚动边界。
- **公式框过窄**：修改前构造器宽 1271 px、公式框仅 173 px；修改后抽查构造器宽 1249 px、公式框宽 1225 px。公式区保留原来的插入、撤销、重做和预览能力。
- **信息卡问号落位**：显示字段的标题与菱形问号保持在同一标签区，输入框在下方；自动检查未出现该字段重复帮助标记。
- **条目归属不清楚**：页面、输入、重复组子字段、卡片项和输出行分别有身份头和分隔线，技术键／slot 使用已有值显示。
- **复合参数撑行**：Label 来源、条件、绘制开关等不再与普通输入混作一个高大的网格单元；开关与普通参数按独立区域排布。
- **窄栏表格**：三列本地对照和带功能值的公共表格按容器宽度切换排布，功能值的子编辑区单独占行；没有通过裁掉内容掩盖超宽。
- **长标签对齐**：采用弹性行伸展，保留标签自然换行。增加强制换行压力检查，1440／600／390 px 下共 6 组检查，同排控件顶部误差为 0；同时避免 subgrid 在该极窄标签边界的布局问题。

修改前证据保留在 [现状检查记录](runtime-v32-editor-visual-20261016/README.md)，修改后截图见 [本轮验收证据](runtime-v32-editor-visual-implementation-20261016/README.md)。

### 3.2 查看与编辑行为

- 浏览、读取、滚动、展开、调整窗口和查看帮助后，活动配置序列化内容的 SHA-256 保持一致。
- 修改工作流标题时，输入 DOM 节点和焦点保留；公式插入后的撤销／重做正常。
- 存在要素草稿时切换工作区仍被阻断，放弃后可以正常切换。
- 表格绑定后选项只读，来源更新会立即反映到界面；解除绑定复制当前有效对照并恢复独立编辑。
- 信息卡字段绑定后来源字段不可编辑，解除后恢复可编辑。
- 内嵌运行预览填写人页的 4 个代表节点，其字号、行高、字重、最小高度和上下内距，在启用／停用本轮编辑器样式作用域时没有差异。

这些浏览器操作使用独立 profile 和独立验收夹具，没有操作用户浏览器中的本地配置。绑定交互夹具的修改仅存在于该夹具内存中。

## 6. 建议用户快速人工确认

1. 打开 [本地生产预览](http://127.0.0.1:5197/?workspace=config-studio&configMode=v3)，依次查看总体规则、要素设计、工作流设计的模块边界与文字对齐。
2. 要素设计选择 ROD 并读取，查看字段身份设置、第二行操作、渲染规则适用范围、Label 来源和信息卡项；试用菱形问号。
3. 放弃草稿后进入工作流设计，读取道路，展开 ConnectL 重复组，检查 mode／tgt；展开输出公式构造器，检查整行输入和撤销重做。
4. 读取 TPP，查看额外绘制的条件、返回格式、高度输入和字段绑定是否清楚分区。
5. 缩窄窗口，并试用浏览器 125%／150%／200%；确认能通过滚动访问所有输入和操作，验证器不会覆盖编辑区。
6. 随意修改一个草稿输入后尝试切换工作区，确认仍有草稿阻断；检查完放弃草稿即可。

开发入口也可使用 [5193 配置工作台](http://127.0.0.1:5193/?workspace=config-studio&configMode=v3)。本轮更新属于前端代码，默认配置仍为契约 r11／配置 r7，不需要重新上传 ZIP。
