## 仍需人工或后续处理的边界

**尚不能宣称 V3 与 V1 整图显示完全一致。** 完整城市诊断单独保存，未列入像素一致性通过项。已修默认楼层差异和背景胶囊隐藏；用户许可的新小胶囊单独计入新增效果。仍观察到：

1. RLE 在 0／1 形成 V1 没有创建的名称 Label，记录包括 `ZRT1_01A`、`ZRT1_01D`、`ZRT7_01B`、`ZRT7_01A`；5／6 的部分线路在 V1 标为 viewport 隐藏，V3 使用 simpleLineLabel。需要在后续渲染轮对照沿线标签资格、锚点与视口策略。
2. Zoom 3 的地理面／站点候选集合及 Zoom 8 的楼层 Label 实际可见性仍有差异，不能由默认分类／数据相同推导为已一致。保留逐条显示对照，不擅自改变已延期的密度、候选和 ROD 排字方案。
3. SVG path 与 DOM Label 计数包含不可见、离屏、部件及点击代理图形，数量差异不直接等于可见缺失；证据同时记录实际视口相交的 Label。

localhost 的 COS 响应没有允许该来源的 CORS 头，外部瓦片也有加载限制。本地受控验收只回放精确发布字节并给测试浏览器添加 CORS 头，应用端点没有改变；这不证明生产 CORS 或瓦片服务通过。真实审核 OAuth、账号角色及保存／批准／发布未在授权测试服务中操作；本轮仅证明身份门禁、禁用／空接口禁网和本地工作区逻辑。前端 ZIP 可选择已注册服务，但不能创建新的后端路由或设置服务器凭据。
