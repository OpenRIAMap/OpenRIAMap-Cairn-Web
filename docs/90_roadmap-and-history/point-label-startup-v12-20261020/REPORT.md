- Web和Pipeline共享同一纯核验内核，支持已发布r11及新增r12。既有审核发布、登录权限、数据链路和不可变配置历史结构保留。

## 性能实测

本机Vite生产预览、隔离Chrome、实际Leaflet地图和世界按钮出现；不是只测加载壳，也不是互联网或所有设备SLA。下表仅20次warm样本，首次下载/完整核验与业务请求另计。

| 基线 | 配置准备P50/P95 | 导航至实际地图P50/P95 | SCF配置请求 |
| --- | --- | --- | --- |
| 当前正式r9/契约r11 | 63.8 / 83.2ms | 122.5 / 147.9ms | 0 |
| 本机r12审查候选 | 65.2 / 82.5ms | 122.0 / 143.4ms | 0 |

r12测量只临时更改本机dist预览指针，身份使用候选真实JSON/manifest摘要，测试后恢复。未改源码public指针或云端。缓存仅复用完整核验结论，仍校验原始字节摘要、解析及本地编译索引；没有通过少画标签来凑启动时长。

密集测试固定60条道路，12次真实平移均显示60条；停止后SVG节点回到60个。CDP发起平移至观察到重新绘制P50/P95为81.66/92.52ms，包含CDP/调度开销，不冒称纯CPU耗时。明确标签预算1时只允许最多1条SVG，其余按严格SVG策略隐藏；还原配置后恢复60条。

## 最后修复的边界问题

1. 新贴线局部路径截取补足英文两端留白，避免短英文被错误判定放不下；CJK字数上限仅统计中文。
2. 新SVG路径更新立即释放被替换旧节点，避免连续平移期间积累渐退节点；停止后节点数固定。
3. 图片pending→failure时恢复圆点半径和交互状态，保证完整基础点回退可见；图片局部偏移实测不移动Label。
4. Class树新增图库声明可随树保存，但不能改掉其他分类共享的既有/并发资源版本。
5. 历史部分点样式覆盖保留基准尺寸、填色和旧半径推导，避免迁移时重置成新默认；当前r9基线没有这类部分覆盖，候选字节不变。
6. 严格SVG下不能执行的HTML/简单文字回退改成明确hide；新配置矛盾同时在表单和共享核验中阻断。
