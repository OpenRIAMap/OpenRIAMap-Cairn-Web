- `npm run verify:config-v32`：56 项门禁通过。`npm run build`：前置完整门禁、TypeScript 和 Vite 生产构建通过。各主题的 verify/build 日志保留在工作区 `migration-runs/postc-v11-20261015/`。
- 新包独立门禁：5,130 组 r10／r11 实际渲染计划与 Label 文本相同；34 份冻结 V1 最终记录完全相同；23 个标准编辑工作流实际样本转换与无修改回灌；28 个工作流和 16 棵 Class 树往返；英文终级回退、系统表范围、冻结版本和 SHA 检查通过。
- 真实测绘 UI：17 个标准 composed 工作流共 34 次提交，使用生产 MeasuringModule、Runner 和地图点击。32 次完整记录直接对照冻结样本；两次 FLR 为满足全局唯一 ID，分别采用唯一 BUD／STB 父记录，原始 34 份冻结记录另由门禁原样核验。`postc-native-workflow-matrix.json` 保存参数化说明和输出。
- TPP：额外目标点 → 主几何页 → 信息页后继续保留最后离开的主几何绘制；回退修改、撤销与再次进入不会串坐标和高度。七类铁路／车站编辑、方向反转、三个 TRP 编辑样本、多部件和洞的实际保存／取消通过。
- 显示交互：九方向乘五组正负偏移、主图和验证器共 90 个真实 DOM 定位通过；各部件 Label／点几何锚点一致且可点击；五种交互态进入／关闭／重开／离开通过；RLE 共 54 组方向和 Zoom 检查通过。
- 实际 Lab：桌面／手机冷启用弹窗、取消、测绘与测量加载，已启用后的直接打开和版本变化后重新加载通过。
- 默认配置：全新浏览器无需上传；旧默认归档、显式旧自定义选择保留、刷新持久化、实际工作流保存、Studio／Lab 同步、历史版本冲突处理通过。升级为隔离草稿，保存／放弃及从 V1 重新生成 r11 的真实入口通过。

所有最终浏览器结果均无运行异常。收录证据见 [acceptance](acceptance/)；完整日志和截图位于上述 migration-runs 目录。截图复核涵盖窄窗标题／帮助、字典编辑、按钮范围／预览、两组瓦片、绘制及编辑界面。

## 简略人工验收

1. 打开 `http://127.0.0.1:5193/?workspace=config-studio&configMode=v3`，确认包 r7／契约 r11。若浏览器显式选过旧自定义版本，先保存需要的草稿，再点“恢复应用默认配置”；无需上传 ZIP。默认未选分类、不挂载显示验证器。
2. 要素设计 → 预留对照表格：新建再删除应恢复未修改；修改一行后区域核验／保存；未保存时切标签应阻断，放弃后可切换。
3. 读取一个分类，在字段、工作流下拉和信息卡中尝试预填／绑定；修改表源并保存，绑定方应更新，独立副本不变。分别解除对照和字段绑定，检查完整可编辑内容与红色解除入口。
4. 总体规则 → 图层按钮：检查 natural_geo 的 ISG/NGF、ISL/NGF 两行；更换图标、颜色和尺寸，单钮／整体预览应立即一致。新增空 Class 行应阻断核验；测试帮助悬停和键盘、缩窄窗口换行。
5. 工作流设计：以 TPP 作为模板创建新 ID，检查额外绘制、条件和组装完整；重复 ID 应阻断。三张标准表不可删除，标准标签目录的合法内容可编辑。
6. 打开 `http://127.0.0.1:5193/?workspace=config-lab&configMode=v3`：启用测绘，测试道路、标准面、TPP 有／无目标 Warp 分支、回退继续绘制和最终输出；用已导入样本尝试铁路／车站／TRP 工作流式编辑。
7. 正式构建另可从 `http://127.0.0.1:5197/?workspace=config-lab&configMode=v3` 验证。两个端口属于不同浏览器存储来源，编辑版本和模块启用状态分别保存。
