## BUTTON-02：按完整分类路径逐行定义显示内容（用户已明确要求）

### 模型与匹配语义

- 每个图层按钮的“显示内容”由多行分类范围组成。每行固定包含 Class／Kind／SKind／SKind2 四个选择框，Class 必填；沿现有分类树级联选择，下级只列当前父级的子分类。
- 选择到某一级并将其后各级留空，表示该分类及其下辖分类。例如仅 Class=ISG 表示 ISG 全部；Class=ISG、Kind=NGF 表示 ISG 下的 NGF 分支。填写深层分类时必须具备合法父路径，不能跨分支拼接。
- 同一行已填写的条件必须同时成立（AND）；同一按钮各行取并集（OR）。多个已开启按钮仍取并集，同一记录命中多行／多按钮只显示一次。
- 每行是一个路径范围，不再分别维护独立的 Class 数组、Kind 数组、SKind 数组和 SKind2 数组，不再产生无法表达对应关系的跨类组合。
- 用户指定的 `natural_geo` 默认内容准确拆为下表，不额外增删其他分类：

| Class | Kind | SKind | SKind2 |
| --- | --- | --- | --- |
| ISG | NGF | 全部下级（未限定） | 全部下级（未限定） |
| ISL | NGF | 全部下级（未限定） | 全部下级（未限定） |

### 编辑与校验

- 用“添加显示内容”增加行，每行可删除。宽屏四框同行，窄容器按宽度换列，仍保持为同一条规则的清晰边界；不得为坚持四列而溢出。
- 下拉框展示分类代码与名称，保存分类代码。未限定子级明确显示“全部下级／不限定”，不与不存在下级、未选择 Class 混淆。
- 改变上级时清除失效的下级选择并明确提示；非法父子组合、未知分类、未填 Class 的新增空行以及没有有效显示内容的图层按钮阻断保存。
- 重复范围或上级已完全包含下级的冗余行给出可定位提示，不把合法并集误判成冲突。排列顺序仅影响编辑呈现，不改变 OR 匹配结果。
- 同步更新主图过滤器、反查命中按钮的接口以及搜索选择后自动开启图层的调用链；不能只更新编辑器或把所有行再压回旧的四个独立数组。

### 旧定义迁移

- 当前默认 `natural_geo` 是 Class=[ISG,ISL]、Kind=[NGF]，迁移为上述两行，当前命中集合保持一致。
- 铁路、建筑、传送等只列多个 Class 的按钮拆成逐 Class 的范围行；各行未限定下级。
- `settlement`、`planning` 等旧规则未填 Class，必须依据现有分类树及已发布记录核对展开为合法路径，保留旧过滤器在现有有效记录上的命中。遇到无法合法表达的旧路径／自定义条件需报告，不能静默漏掉显示。
- 旧的“未限定 Class”可能自动涵盖以后新增的任意 Class；新设计要求 Class 必填，未来新增 Class 需要显式加入相应按钮，此项语义变化需写入迁移说明，不伪称与旧开放匹配对所有未来分类完全等价。
- 契约、schema、默认配置、编译缓存、原生校验、旧包迁移、导入导出与运行器统一升级；下一次正式生成递增版本，不替换冻结 r10/r6 的身份或历史字节。
