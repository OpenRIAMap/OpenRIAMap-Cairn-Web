# c15 测试证据

完整 Web verify:ci 通过；最终 c15 四组测试、相关旧渲染／工作流回归及离线生产 build 再次通过。Pipeline 完整 205 项测试通过。所有本机操作的云端写入数为 0。

实际工作台操作见 [浏览器记录](c15-browser.json)。Chrome 覆盖文件选择、c13→c15、分类／树／工作流核验保存、五种取色、图标对话框、四种图片来源、回退、真实线点击面开关、面内侧开关、类型切换、缓存继续编辑、分类组及新增页面／控件自动展开。同时实际创建 c15 父级模板分类，确认不再生成旧几何级锚点／触发器。共 18 组操作，记录中 `runtimeErrors` 为空。

Chrome 155 与 Firefox 158 都实际检查了 72 组形状／透明度／零描边内部像素、圆形小数、虚线、孔洞、多部件、.5／1.5px 图片环带、SVG 点中判定及单次点击。DPR 1／2 均检查功能；原始样本包含浏览器、视口、P95、长任务支持情况和内存读数。

每轮重置视口，逐一确认全部要素已投影／绘制后采样；不存在通过连续平移把要素移出画面再计时的情况。性能以同一机器、视口、DPR 的 c14／c15 交替预热采样，创建各 7 次，交互汇总各 84 次，每个创建场景随后连续平移 12 次，P95 直接对全部同类原始样本计算。创建包含同步建层、图片解码及两帧初绘等待；同步建层时间单独保留为 `jsCreateMs`，解码数量保留为 `decodedImages`，初绘成本没有被排除或混入首次平移。数值单位 ms。交互目标为 c15 相对 c14 额外≤16.7ms，创建目标为≤c14×1.5+50ms。它们是本机实测，不代表所有硬件保证。

Chrome 三轮功能操作后的强制 GC 观测中，DOM 节点维持 375、监听器维持 25，JS 已用堆约 3.64～3.65MB；这些数值为本机趋势记录，不是跨设备上限。每轮移除后 mask、Halo、活动 MutationObserver 都回到 0，业务 Layer 回到起点。600 折线含虚线，面含孔洞；1200 混合场景同时包含点／图标／线／面。基础形状使用直接环带后，避免了初版密集点遮罩的额外耗时。收紧遮罩到真实描边包络（保留 miter 上限）并跳过相同属性通知；另有 labelsMixed1200 场景，全部符号保留，1200 个请求实际执行 LabelLayout 碰撞和密度计算。c14／c15 的可见／隐藏标签数量一致，完整原始样本保留。首次 Linux CI 曾在混合交互上超出目标 0.5ms；没有降低阈值，随后修正了遮罩开销、初绘计时边界并扩大连续交互样本，再次检验。

真实 GitHub 登录、SCF／COS、生产审核和发布确认没有在本机测试中执行，部署后按主说明验收。Firefox 的这一轮验证覆盖 Halo 与真实 SVG 交互和性能；完整工作台文件操作在 Chrome 验收。
