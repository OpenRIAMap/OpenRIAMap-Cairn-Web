# 测绘工作流桥接维护约定

结构编辑的唯一所有者是 `core/MeasuringModule.tsx` 中现有的“多部件和内洞设置”。正式工作流、工作台试运行和专用流程不得另外增加添加部件/孔环入口或独立追加器。

`WorkflowDrawingDraft` 是内存中的完整编辑快照：几何、活动部件/内洞、面板、编号只读及当前路径历史。它不是配置契约字段或要素属性。`NativeDrawingSession` 在原模块重置前归档，激活正确模式后恢复；重复进入同一活动任务不初始化，未完成结构和不兼容草稿也不得被截断或丢弃。

`getTempPoints()` 供原工具编辑当前路径；正式通用工作流读取 `getDrawingDraft()`。`setDrawingGeometry()` 继续供既有专用流程使用；任务恢复使用 `restoreDrawingDraft()` 保留编辑目标。权限必须由当前实际分类和既有部件政策下发，未选分类不得回落到旧完整模式分类。退出/暂停的目标上下文必须收尾。

编号显示时所有坐标写入、已有工具、撤销/键盘及晚到的回调均只读。结构锁与工具自身拥有的坐标事务不能混为一谈。`prepareDrawingTransition()` 允许原工具按其既定确认方式处理未保存事务；拒绝切换不清草稿，不把上一任务的编辑事务带到下一任务。

桌面和紧凑面板复用同一原编辑器及稳定的工作流 portal，改变布局不能等同于退出或清空。专用铁路/车站/TRP 算法和批准的合并工具仍保留，桥接变更须回归它们。

修改后必须实际操作原部件/内洞控件，保存后比较全部 CoordP/CoordL/CoordG，再回读、导出、导入；仅检查平面点数组、按钮存在或最终类型合法不足以验收。新增用户入口必须有明确批准的蓝图依据，提交说明应列出入口新增/删除/变化。

固定图形构建必须接收完整 geometry，不能使用提交器同时返回的第一路径 coords 代替。验收要在首次保存后、进入编辑前检查实际 SVG 的全部部件和洞。

当前活动任务的图形只由主编辑器绘制；NativeDrawingPreviews 只缓存已核验的其他任务参考图形，非交互且位于编辑器下方。达到合法点数不能触发第二层完整实线覆盖。暂停、任务条件和显式丢弃均须清理对应参考。

控件权限使用当前渲染的模式/分类，进入编辑同步建立事件 ref，不依赖 effect 更新 ref 后的偶然重绘。分类诊断解释现有范围/类型/值核验，不新增“父节点不可保存”或“字段组必须相等”的政策。
